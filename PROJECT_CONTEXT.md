# Himalayan Argali — Project Context

## Status

This is the shared working context for the Himalayan Argali (HA) ecosystem. It is a living document and must remain aligned with the more detailed documents in `docs/`.

## Operating model

- **Founder** — owns vision, budget, direction, partnerships, and final approval.
- **ChatGPT** — leads business strategy, brand architecture, UX, customer journeys, information architecture, and cross-system review.
- **Claude Code** — leads documentation, specifications, editing, and documentation quality.
- **Codex** — leads Shopify, GitHub, theme code, applications, APIs, automation, and engineering delivery.

## Working rules

1. GitHub is the shared source of truth.
2. Important decisions become documentation.
3. Architecture and specifications precede implementation.
4. Only one tool should hold uncommitted repository changes at a time.
5. Never commit credentials, customer data, private Shopify URLs, unpublished theme IDs, or confidential supplier information.
6. All Shopify changes must be made safely through an unpublished or duplicate theme before publication.

## HA ecosystem

- **Wear** — apparel and active clothing
- **Nourish** — honey, sea buckthorn, nutrition, and wellness
- **Equip** — skating, hockey, cycling, pickleball, and related equipment
- **Explore** — camps, coaching, events, memberships, and experiences

Create and approve the Website Master Plan for `www.himalayanargali.shop` before changing the Shopify theme. The plan covers the homepage, navigation, collections, product pages, cart, checkout journey, content, trust, and future expansion.
