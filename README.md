# Himalayan Argali

Himalayan Argali (HA) is a lifestyle brand built around healthy, active, outdoor living.

This repository is the shared source of truth for the brand, product system, Shopify work, and future digital experiences.

## Brand pillars

- **Wear** — apparel and technical clothing
- **Nourish** — honey, sea buckthorn, sports nutrition, wellness products, and Nurture Boxes
- **Equip** — skating, hockey, cycling, pickleball, and other sports equipment
- **Explore** — camps, coaching, events, community, and active experiences

## Repository structure

- `docs/` — brand strategy, product architecture, and decisions
- `shopify/` — Shopify theme and commerce implementation
- `products/` — product information and catalogue structure
- `assets/` — approved brand and product assets

## Working principles

- Build a coherent brand before expanding the catalogue.
- Keep customer trust, product quality, and provenance visible.
- Use Shopify as the commerce platform.
- Record important decisions in this repository.
- Make changes traceable, reviewable, and reversible.
