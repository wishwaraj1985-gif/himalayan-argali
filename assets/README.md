# Assets

Approved brand and product assets for Himalayan Argali.

"Approved" is the operative word. If an asset is in this folder, it can be used without asking. If it is not here, it is not cleared.

## What belongs here

- Logo files in the formats and lockups that are actually approved
- Colour and typography definitions
- Product photography that has been reviewed and signed off
- Iconography, patterns, and other reusable brand elements
- Templates for recurring formats

## What must never be committed here

- Imagery of people without documented permission to use it — this includes athletes, coaches, customers, and children
- Third-party or stock imagery whose licence does not permit the intended use
- Supplier or manufacturer photography shared in confidence
- Any file containing embedded personal data or location metadata that should not be public
- Unreleased product imagery ahead of an announcement

This repository is public. An asset committed here is published, regardless of intent.

## Suggested structure

```
assets/
  logo/           Primary marks, lockups, clear-space rules
  colour/         Palette definitions and usage rules
  type/           Typefaces, licensing notes, hierarchy
  product/        Approved product photography, by pillar
  templates/      Reusable layouts for recurring formats
```

Add folders as real assets arrive.

## File conventions

- Lowercase, hyphenated filenames: `ha-logo-primary-dark.svg`
- Include the variant in the name, not only in the folder
- Vector where possible (SVG); raster at a stated resolution
- No spaces, no version numbers in filenames — git holds the history
- Large binaries add up; keep only what is genuinely reusable

## Rights and permissions

Every asset involving an identifiable person needs a recorded basis for use. Keep the underlying release documents in private storage; note here only that clearance exists and roughly what it covers.

For imagery involving minors — likely across Explore camps and youth Nurture Boxes — treat the default as *do not publish* until permission is explicit, documented, and current.

## Consistency

The brand character HA aims for is authentic, energetic, grounded, adventurous, trustworthy, inclusive, and purposeful. An asset that reads as generic stock or overstated marketing works against that, whatever its technical quality.
